## Simple Split

This repo now runs as a Vite + React frontend instead of a Next.js app.

## Scripts

```bash
npm run dev
npm run build
npm run start
```

`npm run dev` starts the Vite dev server, `npm run build` creates a production bundle, and `npm run start` previews the built app.

## Notes

The old Next.js app router, middleware, and Clerk server integration were removed. The current app is a client-side React shell you can extend with your own state, API, or auth layer.
